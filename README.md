# TOP ROAD — 궁수 대군 돌격전

궁수 부대를 이끌고 숫자 게이트를 지나며 병력을 불리고, 적 대군·거인·보스를 화살 세례로 무찌르는 3D 러너 게임입니다.
브라우저에서 바로 실행되며(모바일 세로 화면 최적화, PC 가로 화면 지원), 외부 이미지·사운드 에셋 없이
모든 그래픽과 효과음을 코드로 생성합니다.

## 실행 방법

ES 모듈을 사용하므로 로컬 웹 서버로 열어야 합니다.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

### GitHub Pages 배포

`.github/workflows/pages.yml` 이 포함되어 있습니다. 저장소 **Settings → Pages → Source** 를
**GitHub Actions** 로 설정한 뒤 `main` 브랜치에 푸시하면 자동으로 배포됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 화면 드래그 (좌우) | 부대 이동 |
| ← / → 또는 A / D | 부대 이동 (PC) |
| P / Esc | 일시정지 |
| Enter | 메뉴에서 전투 시작 |

부대는 자동으로 전진하며 화살을 쏩니다. 좌우 위치를 조절해 **무엇을 쏘고 어디로 지나갈지** 결정하세요.

## 게임 규칙

- **숫자 게이트**: 지나가면 병력이 `+N`, `×N` 만큼 변합니다. 빨간 `−N` 게이트는 병력을 잃지만,
  **화살로 쏘면 숫자가 올라가** 양수로 바꿀 수 있습니다.
- **바리케이드 / 돌기둥 / 거인 / 보스**: 표시된 숫자는 체력입니다. 부딪히면 **병력과 숫자를 1:1로 교환**하므로
  도착하기 전에 화살로 최대한 깎아야 합니다.
- **적 병사**: 닿으면 병사 1명과 아군 1명이 함께 쓰러집니다. 방패병은 화살을 더 맞아야 합니다.
- **보상 통**: 숫자만큼 맞히면 부서지며 보상을 줍니다. 부수지 못하고 지나가면 튕겨 나갑니다.
  - 🧑‍🤝‍🧑 병사 증원 · 🏹 무기 강화(활 → 쇠뇌 → 화염 쇠뇌) · ⚡ 연사 속도 증가
- **보스전**: 도로 끝에서 부대가 멈추고 보스가 다가옵니다. 바닥의 **빨간 원**이 나타나면 옆으로 피하세요.
- 승리하면 골드를 얻고, **강화** 메뉴에서 시작 병력·공격력·연사 속도·전리품을 올릴 수 있습니다.

## 스테이지

레벨 1은 수작업으로 설계된 튜토리얼 겸 광고 재현 스테이지이며, 레벨 2부터는 템플릿을 조합해
예상 병력에 맞춰 난이도를 자동 조절하는 절차적 스테이지입니다. 테마가 순환합니다.

1. 푸른 바다 다리 — 반짝이는 바다 위의 석조 다리
2. 서리 숲길 — 눈 내리는 침엽수 숲
3. 황금 초원 — 꽃과 나무가 있는 흙길
4. 용암 요새 — 흐르는 용암과 불씨

## 기술 구성

- **렌더링**: [three.js](https://threejs.org) r180 (`vendor/` 에 포함, CDN 불필요)
  - 인스턴싱으로 수천 명의 병사 표시, PCF 소프트 그림자, 블룸 + 비네트 후처리, Neutral 톤매핑
  - 바다/용암 셰이더, 림 라이트·피격 플래시 셰이더, GPU 빌보드 파티클, 발광 화살 궤적
  - 화면이 느리면 자동으로 화질을 낮춤 (설정에서 수동 선택 가능)
- **타격감**: 히트스톱, 트라우마 기반 화면 흔들림, 화면 플래시, 넉백 사망 연출, 파편 물리, 데미지 숫자, 진동(모바일)
- **사운드**: WebAudio 합성 효과음과 배경음 (에셋 파일 없음)
- **저장**: `localStorage` (진행 레벨, 골드, 강화, 설정)

```
index.html          UI 마크업 + import map
css/style.css       UI 스타일
js/main.js          부트스트랩, 메인 루프, UI 이벤트
js/engine/          렌더러·후처리, 이펙트, 오디오, 입력, 유틸
js/world/           테마, 절차적 텍스처, 캐릭터/소품 모델, 지형
js/game/            게임 규칙: 부대, 적 군단, 거인/보스, 화살, 게이트·장애물, 레벨 생성
js/ui/ui.js         HUD, 메뉴, 상점, 결과 화면
tools/              한글 폰트 서브셋 갱신 스크립트
```

UI 문구를 바꿔 새로운 한글 글자가 생기면 `python3 tools/update-font-subset.py` 로 폰트 서브셋을 다시 만들어 주세요.
